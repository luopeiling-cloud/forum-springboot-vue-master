# 部署说明

Docker Compose 一键部署后端（6 个业务服务 + 5 个中间件，共 11 个容器），镜像全部从容器镜像仓库拉取，服务器无需访问 Docker Hub。

## 目录结构

| 文件 | 作用 |
|------|------|
| `docker-compose.yml` | 编排文件（所有镜像从 `${REGISTRY}` 指定的仓库拉取） |
| `.env` | 环境变量（含密钥，勿提交/外传）：MySQL 密码、七牛 AK/SK、REGISTRY |
| `.env.example` | `.env` 模板 |
| `doc/docker/init/*.sql` | MySQL 首次启动自动初始化（forum-test 14 张业务表 + xxl_job 表） |
| `uploads/` | 本地图片兜底目录（空目录） |

## 前提

- Linux 服务器，已安装 Docker Engine + Compose 插件
- 服务器可访问镜像仓库地址
- 建议 2C8G 及以上配置

## 步骤

1. 上传本目录到服务器（如 `/opt/forum/`）；`scp` 不传空目录则手动 `mkdir uploads`
2. 复制 `.env.example` 为 `.env` 并填写：`MYSQL_ROOT_PASSWORD`、`QINIU_ACCESS_KEY`、`QINIU_SECRET_KEY`、`REGISTRY`（如 `registry.cn-hangzhou.aliyuncs.com/<命名空间>`；服务器与仓库同地域时可用内网地址免公网流量）
3. ES 所需内核参数：`echo 'vm.max_map_count=262144' >> /etc/sysctl.conf && sysctl -p`
4. 登录镜像仓库：`docker login <仓库域名>`（用户名 + 仓库控制台「访问凭证」设置的固定密码）
5. 启动：`docker compose up -d`；`docker compose ps` 等待全部 healthy（首次含 MySQL 初始化，约 1-2 分钟）

## 安全组

| 端口 | 用途 | 建议 |
|------|------|------|
| 88 | Gateway（前端唯一入口） | 对公网开放 |
| 8848 / 9200 / 3306 / 6379 / 8801-8805 / 8080 | Nacos / ES / MySQL / Redis / 业务服务 / XXL-Job | 不对公网开放 |

## 验证

- `curl http://127.0.0.1:88/api/platform/category/getCategoryTreeData` 返回分类 JSON
- Nacos 控制台服务列表出现 6 个 `forum-*` 实例
- 前端 `forum-web/utils/request.js` 的 `BASE_URL` 指向 `http://<服务器IP>:88/api`

## 更新代码

1. 本地：`build-all.bat` 打包 → `docker compose build --provenance=false` 构建镜像 → `push-images.bat` 推送仓库
2. 服务器：`docker compose pull && docker compose up -d`

## 存量数据进 ES

- 方式一：XXL-Job 调度中心创建任务（JobHandler `noteJobHandler`，执行器 appname `forum-xxl-job-executor`）并手动执行
- 方式二：直接调用批量接口 `POST /api/search/note/addNoteBulkData`（JSON 数组，字段见 `NoteSearchVo`）
- 新发帖会实时同步 ES，上述方式仅用于存量补录
